오늘의 개념 · 빅데이터란?

기존의 데이터 관리 및 처리 도구로는 다루기 어려울 만큼 방대한 양의 데이터를 빅데이터라고 해요. 삼엽충 센서는 0.5초마다 10가지 변수를 기록했고, 부표 데이터까지 합치니 사람이 표로 하나하나 보기 힘든 양이 되었죠. 그래서 그래프·상관계수·추세선 같은 분석 도구가 필요했어요.

교과서 속 빅데이터 활용 4가지

  • 오늘과학 실험 · 부표 관측 데이터로 직접 실험하기 어려운 고생대 바다를 분석
  • 오늘기상 관측 · 드론이 모은 대기 산소·이산화탄소·오존층 데이터로 기후 변화 파악
  • 2차시유전체 분석 · 개인에게 발생 가능한 질병 예측
  • 2차시신약 개발 · 질병 치료 물질을 빠르게 찾기

빅데이터의 문제점도 기억해요

  • 충분히 검증되지 못한 데이터 · 타임머신 좌표 오류, 고장 난 부표의 이상값
  • 지나친 데이터 의존 · 데이터가 적을 때 그린 추세선은 쉽게 틀렸어요
  • 사생활 침해 가능성 · 유전체처럼 민감한 데이터는 어떻게 지켜야 할까? (2차시)

과거의 데이터가 현재를 돕는다

페름기 말에는 화산 활동으로 CO₂가 급증 → 지구 온난화 → 해양 무산소·산성화가 일어나 해양 생물 대부분이 사라졌어요. 이런 지질 시대의 빅데이터는 오늘날 기후 변화 예측 모델을 검증하는 데 쓰여요.
