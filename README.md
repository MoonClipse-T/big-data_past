# 크로노스 프로토콜 · 1차시 고생대의 바다

통합과학 2 「과학 기술의 활용 — 빅데이터」 수업용 3D 게임입니다.
타임머신 사고로 고생대(캄브리아기 · 데본기 · 페름기 말)에 떨어진 과학자가 아기 삼엽충이 되어,
먹이사슬 속에서 탈피하며 성장하고, 바다 데이터를 모아 AI 예측과 빅데이터 분석으로 귀환 좌표를 계산합니다.

- 플레이: https://moonclipse-t.github.io/big-data_past/ (패드는 가로 화면)
- 교사용 옵션: `?era=1|2|3` 해당 시대부터, `?skip` 인트로 건너뛰기, `?teacher` 미션 완료 버튼, `?touch` / `?mouse` 조작 방식 강제
- 수업 내용(생물·대사·질문)은 `content.js`에서 고칠 수 있어요.
- 소리 파일은 `assets/audio/`에 넣고 `manifest.json` 목록에 이름을 추가하면 자동으로 쓰여요.
